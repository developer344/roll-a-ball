## Project

- **Game:** Moon Hunter (Roll-a-Ball)
- **Unity version:** 6000.6.4f1 (Unity 6.6)

## How to open and run

1. Clone the repository.
2. In Unity Hub, choose **Add → Add project from disk** and select the cloned `roll-a-ball` folder.
3. Open it with Unity 6.6. The first import takes a few minutes while Unity rebuilds the `Library` folder.
4. Open `Assets/Scenes/StartMenu.unity` and press **Play**. The Play button loads `Assets/Scenes/MiniGame.unity`.

## Controls

- **Move:** W A S D, arrow keys, or the left stick on a gamepad
- **Goal:** collect all 12 moons without getting caught by the enemy
